# Phase 2 — offline diagnostics

Scope: isolated development branch only. Begin with deterministic issue classification, evidence recording, risk ranking, and review gates. No automated writes to production. Production and security-sensitive changes require Founder approval. Before any live crawler pilot, address the Phase 1 network-safety and dependency findings.

Milestones: (1) pure finding classification, (2) immutable audit event schema, (3) dry-run diagnosis, (4) test and rollback evidence, (5) separate Founder review before integration.
